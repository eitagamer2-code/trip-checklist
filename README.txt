旅行準備リストアプリ（スマホ対応版）

ファイル
- index.html : アプリ本体
- manifest.webmanifest : ホーム画面追加用の設定
- sw.js : オフラインキャッシュ用

追加機能
- 持ち物チェックリスト・テンプレート
- 旅行名、行き先、出発日・帰宅日の管理
- 旅行スケジュール／行程表（日時、行き先、滞在時間、メモ）
- 旅行予算と支出管理
- 行きたい場所の登録、訪問済みチェック、Googleマップへのリンク
- 旅行の満足度と感想の記録
- 旅行プランの共有、テキスト保存、印刷画面からPDF保存
- JSONバックアップ（持ち物タブの「データを書き出す」）

公開方法
1. ZIPを展開します。
2. GitHubのリポジトリ直下に index.html、manifest.webmanifest、sw.js をアップロードします。
3. GitHub Pagesを main / root で有効にします。
4. 公開されたHTTPSのURLをスマホで開き、ホーム画面に追加します。

注意
- データは利用中のブラウザ内に保存されます。端末間で自動同期はしません。
- 更新前に「データを書き出す」からJSONバックアップを保存することをおすすめします。
- PDF出力は「管理・出力」→「PDF出力・印刷」を選び、印刷画面で「PDFとして保存」を選択します。
- 行きたい場所の地図リンクはGoogleマップの検索ページを開きます。地図のAPIキーは不要です。
