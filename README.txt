GitHub Pagesへの反映方法
1. ZIPを展開します。
2. GitHubリポジトリの公開フォルダ（通常はリポジトリ直下）で、index.html、sw.js、manifest.webmanifest を置き換えます。
3. 3ファイルをコミットします。GitHub上でコミットが完了したことを確認してください。
4. GitHub Pagesの公開処理が完了してから、Safariで公開URLを開き直します。
5. まだ古い表示なら、URLの末尾に ?refresh=7 を付けて開いて確認してください（URLに既に ? がある場合は &refresh=7）。

大切な注意
- 既存データはブラウザのローカル保存領域にあります。ファイルを置き換える前に、アプリの「管理・出力」などからJSONバックアップを保存してください。
- SafariのWebサイトデータを削除すると、旅行データも消える可能性があります。バックアップ前にサイトデータを削除しないでください。
- データは端末間で自動同期されません。


ポップ・かわいいデザイン・スマホ下部メニュー版：GitHub Pagesのリポジトリで index.html、sw.js、manifest.webmanifest を置き換えてコミットしてください。置き換え前にアプリ内のデータをバックアップしてください。
